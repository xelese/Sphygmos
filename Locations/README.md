# Locations

Use this folder for the canonical version of recurring regions, settlements, and points of interest.

Keep short location beats embedded in scene cards for table speed, then use these files for fuller regional notes, image links, environmental context, and cross-survey reuse.

## Suggested Pattern

- Keep scene cards focused on immediate play and decision points.
- Put reusable regional truth here.
- Use one file per region, then organize it with subsections for cities, towns, villages, routes, and points of interest.
- If a region changes significantly, add a `Current State` update rather than rewriting its baseline identity.
