# NPCs

Use this folder for the canonical version of recurring NPCs.

Keep the short NPC panels embedded in scene cards for quick table reference, then use these files for fuller notes, portrait links, and cross-survey reuse.

## Suggested Pattern

- Keep scene cards to first-impression speed.
- Put reusable NPC truth here.
- If an NPC changes significantly, add a `Current State` note rather than rewriting their core identity.
