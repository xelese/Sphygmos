# Soil Micro-Lense Kit

> - **Purpose:** Detect and stage microbial collapse in soil; determine whether extinction is bottom-up or toxin-based.
> - **Description:** *A brass fold-microscope with arcane focusing crystal, stain ampoules, slide plates, a depth-auger, and a viability clock that counts how long a sample remains readable.*

## Player Reference

### Structured Skill Challenge

**Goal:** Get 2 successes before 1 failure for a clean result.

About 1 minute per depth.

One PC rolls Nature, and a second rolls Medicine or Survival, or one PC rolls both across 3 rounds.

#### Stage A - Proper Collection (Choose One)
- Survival: Select clean sites and avoid contaminated topsoil.
- Nature: Identify representative microhabitats.

#### Stage B - Microbial Read (Required)
- Nature + Medicine

#### Microbial Density Index (MDI)

| MDI | Condition |
|:---:|:--|
| 5 | Normal web |
| 4 | Thinning + patchy colonies |
| 3 | Root-zone "holes," surface still active |
| 2 | Deep layers dead first, surface "last gasp" |
| 1 | Only rare cysts or spores remain |
| 0 | Dormant / ecological death |

## GM Reference

### Structured Skill Challenge

**Goal:** Get 2 successes before 1 failure for a clean result.

About 1 minute per depth.

One PC rolls Nature, and a second rolls Medicine or Survival, or one PC rolls both across 3 rounds.

#### Stage A - Proper Collection (Choose One)
- Survival DC 13: Select clean sites and avoid contaminated topsoil.
- Nature DC 13: Identify representative micro-habitats.

#### Stage B - Microbial Read (Required)
- Nature + Medicine with DC by region state:
  - Stable DC 13
  - Strained DC 14
  - Unstable DC 15
  - Grey Bloom DC 17
  - Dormant DC 16, easier to confirm "empty," harder to learn how fast it happened

#### Microbial Density Index (MDI)

| MDI | Condition |
|:---:|:--|
| 5 | Normal web (Stable) |
| 4 | Thinning + patchy colonies (Strained) |
| 3 | Root-zone "holes," surface still active (Unstable) |
| 2 | Deep layers dead first, surface "last gasp" (Grey Bloom onset) |
| 1 | Only rare cysts or spores remain (late Grey Bloom) |
| 0 | Sterile (Dormant / ecological death) |

### Outcome

#### Success
- **Scientific Clue:** Confirms bottom-up collapse, not toxin-based, and identifies the correct stage.
- **Science Points:** +1

#### Failure
- **Scientific Clue:** False positive toxin signature at MDI 5 because the stain cross-reacts.
- **Science Points:** -1
